# PhonePe High-Fidelity Website Recreation

An unofficial educational recreation of the PhonePe website built for frontend engineering and responsive UI practice.

## Tech Stack

- React 18
- Vite
- JavaScript
- React Router DOM
- Vanilla CSS
- lucide-react

## Highlights

- Responsive desktop and mobile navigation
- High-fidelity landing page and multi-page experience
- Interactive phone preview with safe demo modes
- UPI, recharge, digital gold and merchant Soundbox simulations
- SIP return calculator
- Business, insurance, wealth, press, careers and about routes
- Responsive layouts from mobile to large desktop viewports
- Accessible semantic markup and reduced-motion support
- Production build verified with Vite

## Routes

- `/`
- `/business`
- `/insurance`
- `/wealth`
- `/press`
- `/careers`
- `/about`

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
