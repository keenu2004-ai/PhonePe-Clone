# PhonePe High-Fidelity Website Recreation

An unofficial educational recreation of the PhonePe website built with React, Vite, React Router and Vanilla CSS.

## Tech Stack

* React 18
* Vite
* JavaScript
* React Router DOM
* Vanilla CSS
* Lucide React

## Features

* High-fidelity responsive UI
* Desktop navigation
* Dedicated mobile navigation drawer
* Interactive phone mockup
* UPI payment simulation
* Recharge and bill-payment simulation
* Digital Gold demonstration
* Merchant Soundbox simulation
* SIP return calculator
* Business solutions interface
* Insurance interface
* PhonePe Switch recreation
* Press/news interface
* Responsive download CTA
* Multi-column responsive footer
* Multiple React routes
* Accessibility-focused markup
* Responsive design from 320px to 1920px

## Routes

```text
/
 /business
 /insurance
 /wealth
 /press
 /careers
 /about
```

## Running Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Disclaimer

This project is an unofficial educational recreation and is not affiliated with PhonePe.

It does not process real payments, collect financial credentials, request real OTPs, or provide real financial services.
